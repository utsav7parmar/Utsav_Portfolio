## 📊 Featured Projects

### 🔹 Portfolio Website
A responsive and interactive personal portfolio website showcasing my education, technical skills, projects, achievements, certifications, and professional journey. Designed to provide recruiters and visitors with a comprehensive overview of my expertise and accomplishments.

**Technologies:** HTML5, CSS3, JavaScript, GitHub Pages

---

### 🔹 Breast Cancer Classification Using K-Nearest Neighbors (KNN)
A research-based machine learning project focused on predicting whether breast cancer tumors are benign or malignant using the K-Nearest Neighbors (KNN) algorithm. The project involved data preprocessing, exploratory data analysis, model training, performance evaluation, and result interpretation to support early diagnosis.

**Technologies:** Python, Pandas, NumPy, Scikit-Learn, Matplotlib

---

### 🔹 FraudGuard AI
A real-time fraud detection system developed using machine learning techniques to identify fraudulent financial transactions. The solution leverages the PaySim dataset, advanced data preprocessing, and predictive modeling to improve transaction security while minimizing false positives.

**Technologies:** Python, Machine Learning, Scikit-Learn, Django REST Framework, React

---

### 🔹 Professional Survey Power BI Dashboard
An interactive Power BI dashboard built using survey data collected from data professionals worldwide. The dashboard provides insights into salary trends, job roles, programming language preferences, work-life balance satisfaction, and career challenges through dynamic visualizations, KPIs, and analytical reports.

**Technologies:** Power BI, DAX, Power Query, Data Modeling, Data Visualization
